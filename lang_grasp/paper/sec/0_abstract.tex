\begin{abstract}
Language-driven grasp detection predicts a grasp for the object named in a natural-language prompt.
On Grasp-Anything++, the largest share of failures of a GR-ConvNet + CLIP baseline comes from grasping the wrong object, since its grasp-map regression never ties the prompt to an object.
We propose a region-text contrastive loss that pools visual features over object masks and trains the prompted object to match the prompt better than the other objects and the background; it is applied only in training, so inference needs no masks and keeps the baseline network unchanged.
Averaged over three seeds, it improves the harmonic mean of Seen and Unseen success by 2.5 points, and restricting grasps at inference to Grounding DINO boxes or ground-truth masks adds up to 6.1 and 16.2 Unseen points, showing that object grounding remains the main bottleneck.
\end{abstract}
