\section{Introduction}
\label{sec:intro}

Grasp-Anything++~\cite{vuong2024language} defines language-driven grasp detection: given an RGB image and a prompt such as ``pick up the pear by its stem'', predict a 2D grasp rectangle $g = (x, y, w, h, \theta)$ for a two-finger gripper.

Before proposing a method, we ask where a simple baseline fails.
We reproduce GR-ConvNet + CLIP~\cite{kumra2020antipodal,vuong2024language} and classify 1,000 of its failures with two vision-language models: about 47\% grasp another object than the prompted one, and about 34\% have a wrong grasp shape on the right object.
The baseline's loss only says where to grasp; nothing tells its encoder, trained from scratch, which object a prompt names.

We contribute this failure analysis, a training-only region-text contrastive loss whose negatives are the other objects of the same scene, and a 7.5-point gain on unseen classes that, as the same analysis shows, comes mostly from fewer missed predictions.
