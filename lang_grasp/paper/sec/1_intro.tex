\section{Introduction}
\label{sec:intro}

Grasp-Anything++~\cite{vuong2024language}, built on the synthetic Grasp-Anything~\cite{vuong2023grasp}, defines language-driven grasp detection: given an RGB image and a prompt, predict a 2D grasp rectangle $g = (x, y, w, h, \theta)$ for a two-finger gripper.
% "such as ``pick up the pear by its stem''": Remove this

As we reproduce GR-ConvNet + CLIP~\cite{kumra2020antipodal,vuong2024language} results, we then use two VLM models to judge its random 1,000 failures, and we find that 47\% grasp another object than the prompted one, while 34\% have a wrong grasp on the right object, such as a wrong angle $\theta$ or width $w$.
Its grasp-map regression loss only tells the model where to grasp, but nothing tells the model which object the prompt names.
