\section{Introduction}
\label{sec:intro}

Grasp-Anything++~\cite{vuong2024language}, built on the synthetic Grasp-Anything~\cite{vuong2023grasp}, defines language-driven grasp detection: given an RGB image and a prompt, predict a 2D grasp rectangle $g = (x, y, w, h, \theta)$ for a two-finger gripper.
% "such as ``pick up the pear by its stem''": Remove this

We reproduce GR-ConvNet + CLIP~\cite{kumra2020antipodal,vuong2024language} and let two vision-language models judge 1,000 random failures over three seeds: 49\% grasp an object other than the prompted one, while 36\% grasp the right object with a wrong pose.
Its smooth L1 loss supervises only the output grasp maps, so it tells the model where to grasp geometrically, but nothing explicitly tells the model which object the prompt names.
