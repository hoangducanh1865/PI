\section{Related work}
\label{sec:related}

GR-ConvNet~\cite{kumra2020antipodal} formulates antipodal grasp detection as pixel-wise regression, encoding an RGB image with residual convolutional layers to decode grasp quality, angle, and width maps.
Grounding DINO~\cite{liu2024grounding} performs open-set object detection by fusing visual and language features in a Transformer detector to ground text phrases into bounding boxes.
Contrastive learning with the InfoNCE loss~\cite{oord2018cpc} pulls positive pairs together and pushes negative pairs apart in a shared embedding space; CLIP~\cite{radford2021clip} pretrains transferable visual-text encoders via image-text contrast, while ALBEF~\cite{li2021albef} aligns image and text features contrastively before cross-attention fusion.
Grasp-Anything~\cite{vuong2023grasp} synthesizes large-scale grasp annotations from foundation models, and Grasp-Anything++~\cite{vuong2024language} pairs them with natural language grasp instructions.
