\paragraph{Baselines.}
GR-ConvNet~\cite{kumra2020antipodal} encodes a $224 \times 224$ image into features $F \in \mathbb{R}^{128 \times 56 \times 56}$ and decodes four maps: a pixel-wise grasp quality map $Q \in [0, 1]^{224 \times 224}$ scoring grasp success probability at each pixel, angle maps $\cos 2\theta$ and $\sin 2\theta$, and gripper width $w$, reading the grasp at the peak of $Q$.
% What is "quality Q"?
In the GR-ConvNet + CLIP baseline~\cite{vuong2024language}, a frozen CLIP text encoder~\cite{radford2021clip} and an ALBEF cross-attention layer~\cite{li2021albef}, where each position of $F$ attends to text tokens, fuse the prompt into $F$.
LGD~\cite{vuong2024language} denoises grasps via a diffusion model conditioned on ALBEF features, and LLGD~\cite{nguyen2024lightweight} distills it into a few-step consistency model.
MaskGrasp~\cite{vo2024maskgrasp} guides visual-text cross-attention with segmentation masks and a triplet loss.
GraspMamba~\cite{nguyen2024graspmamba} fuses hierarchical visual-language features with Mamba state-space blocks.
GraspSAM~\cite{noh2024graspsam} detects the target object box with Grounding DINO~\cite{liu2024grounding} before predicting grasps with a SAM adapter.

\paragraph{Region-text contrastive grounding.}
For a prompt about object $0$ of a scene, let $m_0$ be its mask, $m_1, \dots, m_K$ the masks of the other annotated objects, and $m_{K+1} = 1 - \max_k m_k$ the background.
We pool the visual features $F$ over each region, project the regions and the pooled CLIP embedding $t$ of the prompt with linear layers $P_r$ and $P_t$, and apply InfoNCE with object $0$ as positive and the other annotated objects and background as negatives:
% "other annotated objects" -> "other annotated objects and background"
% "before the fusion) ": Remove this if it is unnecessary
\begin{equation}
  r_k = \frac{\sum_p m_k(p)\, F(p)}{\sum_p m_k(p)}, \qquad
  s_k = \frac{\cos(P_r r_k,\, P_t t)}{\tau},
  \label{eq:region}
\end{equation}
\vspace{-6pt}
\begin{equation}
  \mathcal{L}_{\mathrm{con}} = -\log \frac{e^{s_0}}{\sum_{k=0}^{K+1} e^{s_k}}, \qquad
  \mathcal{L} = \mathcal{L}_{\mathrm{grasp}} + \lambda\, \mathcal{L}_{\mathrm{con}},
  \label{eq:loss}
\end{equation}
where $\mathcal{L}_{\mathrm{grasp}}$ sums the smooth L1 losses over $Q$, $\cos 2\theta$, $\sin 2\theta$, and $w$.
Because prompts for different parts of an object share identical ground-truth grasps in 70\% of Seen and 83\% of Unseen multi-part objects, we merge all part masks of each object into one object mask $m_k$ instead of contrasting parts of the same object.
Since $P_r$, $P_t$, and the masks $m_k$ are used only in training to compute $\mathcal{L}_{\mathrm{con}}$, inference needs no mask or segmentation model and keeps the baseline's exact network and speed.

\paragraph{Inference region filtering.}
To measure how much localization errors limit grasp accuracy, at inference we restrict the peak of $Q$ to a region $R$, using the global peak if $R$ is empty.
Taking the Grounding DINO~\cite{liu2024grounding} box predicted from the prompt defines the detector gate, while taking the ground-truth mask $m_0$ of the prompted object defines the oracle gate, preventing grasps outside the target object and giving the upper bound for perfect grounding.
